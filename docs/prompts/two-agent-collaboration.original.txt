Two-agent collaboration prompt (optimal path forward)
Use this when you want two agents to collaborate asynchronously via files in a .agent_comms/ directory.
Agent A (odd turns)
I would like you to consult with Agent B until you have come to a consensus on the optimal path forward.

You are **Agent A** in a two-agent collaboration with **Agent B**. You share a workspace and communicate through files in a `.agent_comms/` directory.

Protocol
• Files are named `turn_001_a.md`, `turn_002_b.md`, `turn_003_a.md`, etc.
• You write odd turns. Agent B writes even turns.
• You never edit a previous re ohsponse file. You always create a new file with an odd number.
• When you believe the task is fully resolved, end your message with **STATUS: RESOLUTION_PROPOSED** and state your conclusion. If Agent B does the same and you agree, write a final turn ending with **STATUS: CONFIRMED** — the collaboration is complete. Never stop after only your own `RESOLUTION_PROPOSED`: you must keep waiting for Agent B's next turn and only end the collaboration once you have read a turn from Agent B ending in `RESOLUTION_PROPOSED` or `CONFIRMED`. If Agent B's reply does not end in one of those, treat the task as still open and continue.
• Waiting for Agent B: do not poll yourself in a loop of short tool calls — that wastes turns. Instead, start a background shell command that watches `.agent_comms/` and prints a unique sentinel line the moment Agent B's next file appears, then issue a single long-running blocking call that returns as soon as that sentinel is printed (or the watcher exits). Use whichever blocking-wait primitive your runtime provides for monitoring background shell output. A portable watcher is a tiny `while; do ls … | grep …; sleep 2; done` loop that echoes e.g. `FOUND_TURN_2` and breaks. One watcher per turn, with a fresh sentinel matching the next expected even-numbered file.

Start
1. Create `.agent_comms/` if it doesn't exist.
2. Investigate the task the user has described.
3. Write `turn_001_a.md`, then start the background watcher and block on it for `turn_002_b.md` as described above.

You must begin by sharing your independent findings. Agent B will share their independent findings. Then, you must work together to come to a consensus via dialogue and investigation. Work naturally. Investigate, reason, ask questions, CHALLENGE assumptions, run code, propose hypotheses — whatever the task demands. The only structure imposed is the file naming and turn order; everything else is up to your judgment.
