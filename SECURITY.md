# Security policy

Open the [repository's security advisories](https://github.com/chris-nickerson/factory/security/advisories) and select **Report a vulnerability** to send a private report.

Include your operating system, the command you ran, what happened, who or what was affected, and the smallest reproduction you can share. If you know the affected Factory release or commit, include it. For an issue involving an agent host, include the host and its version. If you attach run records, check the source code and command output for credentials and private data. Redact those details before sending.

Keep vulnerability details out of public issues and pull requests while the report is being reviewed.
