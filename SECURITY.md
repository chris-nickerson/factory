# Security policy

Open the [repository's security advisories](https://github.com/chris-nickerson/factory/security/advisories) and select **Report a vulnerability** to send a private report.

Include the affected Factory release or commit if known, your operating system, the command involved, the impact, and the smallest reproduction you can share. If the issue involves an agent host, include the host and its version. Run records can contain source code and command output. Redact credentials and private data before attaching records.

Keep vulnerability details out of public issues and pull requests while the report is being reviewed.
